## 一、画风总纲：纸上点兵的东方美学

### 1.1 核心一句话
**“一层古宣作疆土，一身墨线立筋骨；三阶硬光塑形意，朱青两色分敌我；金石印章定乾坤；荒野触控入毫厘。”**

《墨阵山河》依托 WebGL / Three.js r160 运行低面 3D 网格，但其终端视觉绝非普通“Low-Poly 手游”，而是**一幅在玩家指尖徐徐展开、笔走龙蛇的写意古代战阵长卷**。
美术审美的最高铁律是：**关闭全屏墨线描边后，画面应当瞬间失去结构感！** 这一反常识的规则证明画面不是靠贴图纹理支撑，而是纯粹由中国传统绘画的“骨法用笔”撑起的战阵气韵。

│ 步卒人海│ 青玉 #4B7A6A │ 泥土黄       │ 体型最矮(0.92~1.00)，短兵直立，无披风，成队涌动  │
│ 铁壁重盾│ 深青 #2F5D50 │ 朱砂盾缘     │ 轮廓最宽(1.02~1.14)，巨型方盾/圆盾，沉稳如石    │
│ 长枪锐阵│ 青灰 #5E6B62 │ 白缨/红缨    │ 轮廓最高(1.05)，长枪竖举超过身长1.3倍，枪林如刺 │
│ 远程劲弩│ 深靛 #3A4A6B │ 宣纸米白     │ 横向延展，弓弩横置，侧身张弦，后排散点分布      │
│ 铁骑冲锋│ 赭红 #8A4B3A │ 鎏金马鞍     │ 纵深最厚(高1.90)，马匹奔踏+身后大披风猎猎翻飞   │

│ 营垒建筑│ 土褐 #6B5B45 │ 青瓦脊顶     │ 方形高台底座，箭楼立柱，地表高耸固定实体        │

#### 敌我与将领阵亡视觉规范：
- **敌方标识**：敌方单位头顶佩戴朱砂红翎缨，轮廓描边加深 15%，脚下带有微弱墨煞气息；
- **将领力竭阵亡**：
  - **严禁将领阵亡后半透明模糊化**；
  - 阵亡主将**保持原色实体不透明度（`opacity = 1.0`）**，进入凝神调息状态；
  - 仅在主将**脚下地面铺展半透明的翠绿色回春光环（Green Halo Aura）**，脉动扩散，直观传达“战魂未散、回春复原中”的高雅意境。

### 1.4 美术绝对禁区（Red Lines）

1. **严禁写实 PBR 材质**：严禁法线贴图、粗糙度贴图、AO 贴图。所有模型统一为纯色顶点色 + Toon Ramp。
2. **严禁二次元萌系化**：无大眼、无脸部五官贴图。人物面部一律仅有两道冷峻墨线眼。
3. **严禁赛博荧光杂色**：严禁出现荧光粉、电光蓝。特效严格限定在水墨黑、纸色白、朱砂红、青玉绿、玄黄鎏金五色之内。
4. **严禁高面数曲面细分**：严格保持折角多边形风格，圆柱以 5~7 边形为基准，如金石雕刻般的硬朗刀法。

## 三、3D 战场动态指示与教学指引系统

针对新手教学与战术布防，引入高辨识度的三维地脉指示系统：

```
                      [ 悬浮方向指示金箭 ]
                              ↓
                  ◎ ◎ ◎ (动态旋转虚线金环) ◎ ◎ ◎
               ● ───────────────────── ●
                      [ 阵位金色聚光地面斑 ]
```

1. **3D 战场动态金色落位指示光环（Target Ring）**：
   - 当教程或特定战术提示玩家出兵时，在目标战场地面坐标实时投射**金黄色虚线旋转靶心光环**；
   - 光环带有 2.5 弧度/秒的顺时针平滑自转与轻微呼吸缩放，外沿辅以金色半透明扩散波纹；
2. **悬浮方向指示金箭（Pointer Arrow）**：
   - 目标阵位正上方悬浮朱金双色高对比箭头，沿 Y 轴平滑往复浮动，直观指示“在此处战场点击出兵”；
3. **手势与聚光灯联动**：
   - 配合 UI 层高对比金红配色军师手势，指引玩家严格在发光阵位内完成部署。

## 六、移动端响应式与视口自适应标准

针对手机设备（尤其是 16:9 与 20:9 横屏视口及屏幕高度较低场景）执行严格的自适应准则：

1. **操作栏强制吸底（Sticky Action Buttons）**：
   - 关卡详情操作区（`.detail-actions`）采用 `position: sticky; bottom: 0;`；
   - 底部覆盖宣纸雾化渐变（`linear-gradient(180deg, transparent, rgba(239, 230, 211, 0.98) 30%)`），确保无论关卡详情文本多长，【出 征】按钮永远浮现在视口右下方，绝不偏出屏幕；
2. **聚光灯指引居中自适应**：
   - 在 `FirstGuide` 引导聚焦任意目标时，底层强制触发 `targetEl.scrollIntoView({ behavior: 'smooth', block: 'center' })`；
   - 提示气泡根据边界智能计算，在下边缘自动翻转至目标上方，杜绝被手机黑边或导航栏裁切；
3. **紧凑断点规范**：
   - 当视口高度 $\le 600\text{px}$ 时：
     - 章节标签栏高度紧缩 30%；
     - 关卡详情字号与行距自动微调缩减；
     - 确保地图大道与操作区域完美黄金比例分割。

## 七、技术美术（TA）管线与性能指标

### 7.1 单 Pass 综合水墨后处理着色器
纯前端 Three.js 保证 60 FPS 稳定运行：
- **纸纹混成**：在片段着色器直接按像素混合纸纤维噪声，无需额外全屏贴图；

## 0. 设计哲学与核心原则

### 0.1 三大不可动摇之设计支柱（Pillars）
1. **纯粹单线，克制至上**：
   单线大道推进，零手牌轮替、零弃牌、零抽卡。战前自选 6 卡全程常驻，胜负取决于对敌军波次节奏的精准预判、军令收支调度与兵种五行克制，杜绝随机发牌挫败感。
2. **名将临阵，绝技破阵**：
   吸纳《荒野乱斗》（Brawl Stars）顶级动作战术快感，构建**“普攻充能大招（Q 键 100% 触发）+ 7 级专属技能（E 键 20s 冷却）+ 3 级被动光环”**的动作化英雄体系。主将走位领阵，残血不屈，阵亡不透明，回春重聚。
3. **纸上点兵，金石立威**：
   以古宣为底、浓墨勾骨、三阶硬光塑面。UI 与战斗反馈彻底融入传统金石笔墨语言：暴击如汉印砸落、击杀如墨爆散华、卡面如竹简玉佩、大捷如展卷盖印。顶部资源栏与通用嘉奖展台全面看齐现代顶级竞技手游质感。

### 0.2 绝对不可做清单（Never-Do List）
- **绝不加入战内手牌轮替/抽卡/弃牌**：6 个卡槽就是 6 个战前承诺，卡面永远固定可见；
- **绝不做多线分路稀释视觉**：聚焦单线大道纵深密度与阵地攻防；
- **绝不在失败瞬间弹全屏强插广告**：失败复盘只提供战术分析与一键再战，广告仅作为自愿选择的补给翻倍；
- **绝不做无保底的广告体验**：无尽门票无上限获取，任务领赏一键翻倍，观看即得。

## 1. 核心战斗系统（Battle System）

### 1.1 战场宏观结构与空间坐标
- **战场坐标系**：
  - X 轴为推进横向（全长 32 世界单位），Z 轴为排布纵向（宽 5 世界单位），Y 轴为垂直高度。
  - 我方帅帐基线：`PLAYER_BASE_X = -13.5`（基础耐久 3000）
  - 我方合法出兵区：`x ∈ [-14.0, -2.5]`（部分伏兵与先锋可部署至敌后）
  - 敌方营寨基线：`ENEMY_BASE_X = 13.5`（普通关卡耐久 1200 ~ 11000 递增；无尽模式恒定 5000 HP 并带反噬重生）
  - 敌军刷新点：`ENEMY_SPAWN_X = 15.5`
  - 主将活动范围：`x ∈ [-14.0, 4.0]`，主将可沿大道自由调度走位，但不可单骑深入敌寨门下。
- **军阵位（Building Pads）**：
  大道我军半场固定布设 4 个八卦军阵地脉，箭塔、连弩塔、战鼓、医帐等建筑仅可落子于军阵位上，建筑不可移动且免疫击退。

### 1.2 军令资源与常驻 6 卡模型

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  卡位 1 (步) │ │  卡位 2 (枪) │ │  卡位 3 (弓) │ │  卡位 4 (盾) │ │  卡位 5 (骑) │ │  卡位 6 (策) │
│  消耗: 4 令   │ │  消耗: 5 令   │ │  消耗: 7 令   │ │  消耗: 4 令   │ │  消耗: 6 令   │ │  消耗: 8 令   │
│  [就绪·流水]  │ │  [冷却中·3s] │ │  [缺令·抖动]  │ │  [就绪·流水]  │ │  [禁用·石锁]  │ │  [蓄势·微缩]  │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

- **军令（Energy）机制**：
  - 开局初始军令：15 点；
  - 基础军令上限：30 点（通过大本营军令营升级最高可达 50 点）；
  - 基础回复速率：1.0 点/秒（受军令营等级与肉鸽增益加成）；
  - 击杀回令：击杀普通单位回令 +1，击破建筑回令 +8，斩杀首领瞬间补给 +20 军令并刷新大招。
- **卡面五态状态机**：
  1. **就绪态（Ready）**：军令充足且冷却归零，青玉流光微波，轻触即刻选定；
  2. **缺令态（Short）**：冷却已毕但军令不足，朱砂红边提示，强点触发物理抖动与短促提示音；
  3. **冷却态（Cooldown）**：降饱和 55% 水墨遮罩，顺时针扇形消退并居中显示倒计时；
  4. **蓄势态（Casting）**：选定术法后其余卡牌微缩压暗，战场呼出施法范围圆环；
  5. **禁用态（Disabled）**：受特定关卡异象封印，呈现灰白墨稿剪影。

### 1.3 克制链与伤害公式

建立以 `src/data/counters.js` 为单一权威源的闭环计算模型：

| 克制关系 | 克制方 | 被克方 | 数值/机制实现 | 战术逻辑 |
|---|---|---|---|---|
| **截杀** | 轻骑兵 / 重骑兵 | 远程弓弩 / 谋士 | `mul: 1.30` | 骑兵高速冲刺突脸，近身屠戮脆皮远程 |
| **压制** | 弓兵 / 神臂弓 / 投矛 | 轻装步卒 (乡勇/剑兵/斥候) | `mul: 1.30` | 中远程箭雨覆盖，无重盾掩护的轻步伤亡剧烈 |
| **枪阵** | 长枪兵 / 拒马 | 铁骑冲锋 (轻/重/白马) | `special: anticav` (首击 ×10, 后续 ×5) | 枪林如刺阻截马蹄，冲锋撞击溃灭并击停 |
| **拆械** | 刺客 / 伏兵 | 攻城车 / 投石车 | `mul: 1.35` | 刺客贴身破坏笨重器械，攻城器械无法还击 |
| **贴身** | 剑兵 / 刀盾兵 | 长枪兵 | `mul: 1.20` | 贴身短兵相接，长枪受制拉不开刺击距离 |
| **破寨** | 霹雳车 / 火药车 | 敌方建筑与营寨 | `special: siege` (霹雳车 ×1.5, 火药车 ×4.0) | 巨石轰击与烈性火药，专克工事要塞 |

- **伤害统一结算公式**：
  $$\text{Damage} = \max\left(1, (\text{Atk} \times \text{SkillMul} \times \text{BuffMul} - \text{TargetArmor}) \times \text{CounterMul} \times \text{CampAtkMul}\right)$$
  所有攻击、攻速、减伤加成严格受全局硬上限约束（攻击 $\le +60\%$，攻速 $\le +60\%$，减伤 $\le 45\%$）。

## 2. 荒野乱斗式名将绝技体系（Heroes & Mechanics）

摒弃传统卡牌“数值加成挂件”思路，将将领打造为具备高辨识度动作手感与战局颠覆力的战术核心：

### 2.1 三大技能槽位架构

```
┌────────────────────────────────────────────────────────┐
│ 主将普攻 ──> 每次命中充能 +5% (大招期间不充能)           │
│                                                        │
│ ┌──────────────────────┐    ┌────────────────────────┐ │
│ │ 专属技能 (按 E / 按钮)│    │ 主动大招 (按 Q / 按钮) │ │
│ │  【7级解锁 · 冷却20s】│    │  【100%充能 · 冷却50s】 │ │
│ │  解控 / 击退 / 爆发  │    │  全屏流光 · 破阵翻盘   │ │
│ └──────────────────────┘    └────────────────────────┘ │
│                                                        │
│ 被动光环 (3级解锁)：如赵云【一身是胆】低血免伤与团队攻速吸血│
└────────────────────────────────────────────────────────┘
```

1. **普攻与大招充能机制**：
   - 开局大招处于锁定与未充能状态（0%）；
   - 主将每次普通攻击命中敌方单位，大招充能增加 **+5%**（大招释放期间锁定不充能）；
   - 充能达到 100% 且冷却就绪时，右下角 Super 大招按钮点亮金色脉冲流光；
   - 释放大招后充能归零，进入 50s 基础冷却（无尽模式增益与天赋可缩减），冷却期间仍可继续普攻充能。
2. **专属技能（原妙具，7 级解锁）**：
   - 冷却时间 20 秒，**单局战斗不限使用次数**；
   - 达到 7 级即可在战场右下角使用，提供解控、突进、强控或爆发增益。
3. **被动战技（3 级解锁）**：
   - 达到 3 级解锁常驻光环与生存特技。
4. **主将调度与力竭重生**：
   - 玩家可随时点击战场地面调遣主将走位，掌控接火线；
   - 主将生命归零进入力竭蓄势，**模型保持原色实体不透明**（绝不半透明模糊），脚下泛起碧绿回春光环，蓄满后即刻重返战场。

## 4. 关卡矩阵与两大核心模式（Levels & Modes）

### 4.1 四章四十关主线战役
主线由 4 章 40 关严密架构组成：
- **第一章【黄巾之乱】(1–10 关)**：初阵破敌，妖道张角，建立基础兵线与克制认知；
- **第二章【虎牢之围】(11–20 关)**：连弩高台，飞将吕布两阶段狂暴；通关第 20 关开启无尽模式；
- **第三章【官渡博弈】(21–30 关)**：火焚乌巢，河北雄狮袁绍，多机制复合；
- **第四章【赤壁鏖兵】(31–40 关)**：雾锁大江，东风借火，绝境决战奸雄曹操。

### 4.2 墨影试炼 · 无尽模式（Endless Mode）

长线战术验证与核心肉鸽玩法，代码单一权威源：`src/data/endless-manager.js` 与 `src/battle/waves.js`。

```
┌────────────────────────────────────────────────────────┐
│ 通关主线第 20 关（虎牢·吕布）解锁门禁                    │
│ 每日免费赠送 2 次试炼机会；耗尽后看广告无限补充 (+1次/看) │
├────────────────────────────────────────────────────────┤
│ 推进机制：无需等待敌军清屏，每隔 20s 准时推进下一波       │
│ 出兵规模：第1波 5人，每过 5波出兵上限 +2人              │
│ 传奇卡门禁：第 10 波起允许出现，单波数量 ≤ 0.1 * 当前波次 │
├────────────────────────────────────────────────────────┤
│ 敌寨机制：5000 HP，击破触发 80% 反噬 AOE 与 3s 无敌回血   │
│ 肉鸽选牌：每波通关弹出 3 张墨玉牌，【全局物理暂停】选定后继续│
└────────────────────────────────────────────────────────┘
```

1. **解锁条件与门票系统**：
   - 玩家通关第 20 关（`clearedCount >= 20 || stars[20] > 0`）后，胜利界面触发盛大庆贺弹窗解锁无尽模式；未通关前主界面展示锁定标与清晰通关指引；
   - 每日 00:00 自动重置 2 次免费入场门票；
   - 门票耗尽后弹出门票充能窗（`#endless-ticket-modal`），**观看广告无上限补充门票**，看 1 次增加 1 门票，随时可战！
2. **波次递增与传奇卡限制规则**：
   - **定时出兵**：每隔 **20 秒** 准时刷出下一波敌军，无需等待上一波杀绝，考验玩家阵地持续清线与抗压能力；
   - **出兵人数递增**：初始出兵数量 5 人，每过 5 波额外增加 2 人（第 1~4 波 5 人，第 5~9 波 7 人，第 10~14 波 9 人…）；
   - **传奇卡解锁与数量硬上限**：
     - **第 10 波开始才允许敌方刷出传奇卡（如霹雳车）**；
     - 每波敌方传奇卡出兵数量**严格限制在不得高于当前波次的 0.1 倍**（第 10~19 波最多 1 辆，第 20~29 波最多 2 辆），彻底杜绝早期传奇卡满屏泛滥；
   - **首领波次**：每 10 波刷新强敌首领，首领附带专属强化与斩杀赏赐。
3. **敌方大本营反噬与无尽重生**：
   - 敌方大本营基础生命恒定为 **5000 HP**；
   - 当敌寨气血被空降打空时，立即触发**地动山摇爆破反噬**，对身周一定范围我方单位造成 **80% 最大生命值**的巨大反噬冲击波；
   - 敌寨随后进入 **3 秒无敌护盾状态**，生命瞬间重组回满，重新接受攻城挑战。
4. **肉鸽三选一增益与全局物理暂停**：
   - 每一波敌军清剿完成时，屏幕中央弹出 3 张水墨玉佩增益卡牌供玩家三选一；
   - **选卡期间全战场进入全局物理暂停（`paused = true`）**：所有我方单位、敌军士兵、飞行弹道、攻击判定全面冻结，杜绝玩家因思考选卡而导致大本营被偷袭或错失战机；
   - 选牌完毕后即刻恢复正常时间流动；
   - 14 大平衡可调增益库：
     - 【军令如山】：军令恢复速度 +10%
     - 【兵贵神速】：全卡牌部署军令扣减 1 点（最低 1 费）
     - 【神机妙算】：全卡牌冷却时间 -10%
     - 【运筹帷幄】：主将大招与技能冷却时间 -10%
     - 【固若金汤】：帅帐即刻恢复 1500 HP，上限永久 +500 HP
     - 【三军用命】：全军基础攻击提升 +10%
     - 【金戈铁甲】：全军护甲 +2，全队受击免伤 +5%
     - 【枯木逢春】：全场我方单位每秒恢复最大生命 0.5%
     - 【破阵陷阵】：全军暴击率 +10%，对敌方大本营攻城伤害 +20%
     - 【万夫莫敌】：主将攻防神威额外提升 +15%
5. **战后精细结算与广告双倍**：
   - 坚持波次奖励墨宝与将令；斩杀敌兵每 50 人奖 1 墨宝；击败首领额外奖 5 将令；对敌寨每造成 5000 伤害奖 3 墨宝 + 1 将令；
   - 结算展台支持【🎬 观摩广告双倍领赏】，战利品当场翻倍入库。

## 5. 山河悬赏令系统（Bounty System）

参考《荒野乱斗》任务系统重构，代码单一权威源：`src/data/bounty-manager.js` 与 `src/ui.js`。

```
┌────────────────────────────────────────────────────────┐
│ 每日悬赏 (日赏 3项) ──> 难度*2 / 奖励*0.5 / 24h 重置    │
│ 每周悬赏 (周赏 4项) ──> 难度*3 / 丰厚将令 / 周一重置    │
├────────────────────────────────────────────────────────┤
│ 刷新机制：每日免费换一换 2次；耗尽后看广告 +3次刷新     │
│ 领赏机制：支持直接领赏 与 【🎬 看广告双倍领取】          │
│ 界面交互：主页悬赏栏可【收起 / 展开】，记忆于本地存储   │
└────────────────────────────────────────────────────────┘
```

1. **任务节奏与数值重平衡**：
   - **每日悬赏（日赏 3 条）**：任务难度提升至原版的 2 倍（如击杀 60 敌军、部署 40 次士兵、取得 2 胜），奖励调整为 0.5 倍（每条约 20~25 墨宝 + 5~8 将令），强化长线追求；
   - **每周悬赏（周赏 4 条）**：任务目标提升至 3 倍（如累计造成 30,000 伤害、击杀 300 敌军、完成 25 场战斗），周一 00:00 自动刷新；
2. **双倍领赏与一键双倍**：
   - 每次任务达成时，悬赏弹窗提供【领赏】与【🎬 看广告双倍领取】双按钮；
   - 一键领赏同样支持广告翻倍，直接获得 200% 物资收益；
3. **换一换与广告补充刷新**：
   - 每日赠送 **2 次免费换一换** 机会；
   - 免费次数用尽后，按钮变为【🎬 看广告 +3 次刷新】，玩家观看广告即可再获 3 次换任务权利；
4. **主界面折叠收起**：
   - 主界面悬赏栏设有【收起 / 展开】按钮；折叠后化为精致胶囊横条，仅展示“日赏 0/3 · 周赏 0/4”，保持主界面开阔简洁。

## 8. 移动端响应式与多端适配标准（Mobile Responsive）

针对移动端手机屏幕（横屏 16:9 / 20:9 及小高度视口）全量重写 UI 布局：

```
┌────────────────────────────────────────────────────────┐
│ 移动端自适应核心准则：                                   │
│ 1. 关卡详情页操作栏强制吸底 (position: sticky; bottom: 0)│
│ 2. 备战与出征按钮永远常驻可见，绝不因内容滚动被挤出视口   │
│ 3. 字体与行距在小高度视口下自动缩紧微调                 │
│ 4. 所有按键具备 3D 触控回弹按压反馈 (translateY(2px))    │
└────────────────────────────────────────────────────────┘
```

- **操作栏绝对吸底（Sticky Action Buttons）**：
  - 关卡详情（`.level-detail`）的操作区（`.detail-actions`）采用 `position: sticky; bottom: 0`，配合毛玻璃宣纸渐变阴影，即使在高度小于 500px 的手机横屏上，【出 征】按钮永远稳居右侧视口下沿，清晰可见、随时可点；
  - 备战页出战按钮（`#btn-start-battle`）同样执行常驻可见规范；
- **紧凑布局媒体查询**：
  - 在 `@media (max-height: 600px)` 与 `@media (max-width: 900px)` 下，自动紧凑标题字体、收缩间距、缩减章节横栏高度，释放核心操作空间。
